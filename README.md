# Meu Primeiro Projeto HTML 🚀

## 📖 Sobre o projeto

Este projeto é uma página pessoal de links, desenvolvida para reunir minhas redes sociais e perfis profissionais em um só lugar, com uma interface simples, moderna e intuitiva.

A aplicação conta com alternância entre os modos claro e escuro, botões de navegação personalizados, ícones de redes sociais e um visual minimalista com gradientes.

Mais do que uma página de links, este projeto tem um significado especial para mim. Foi meu primeiro contato com HTML, em 2023, quando comecei minha jornada na programação. Foi também uma das primeiras vezes em que percebi que podia transformar linhas de código em algo real.

Em 2026, decidi reconstruí-lo, aplicando os conhecimentos que adquiri ao longo do tempo, mas preservando a essência de onde tudo começou.

## 🛠️ Tecnologias utilizadas

- **HTML5** — Estrutura da página.
- **CSS3** — Estilização, layout e temas visuais.
- **JavaScript** — Interatividade e alternância entre os temas claro e escuro.
